# Stage8A analysis details, frozen before main scoring

Extends the approved plan and main measurement protocol with finite fitting choices. No main passive/causal outcome has been inspected when this file is created. This does not alter the original success thresholds or authorize reinjection.

- Primary R is selected from joint QK/attention and joint plus concentration/temporal logistic probes. Compare attention-only and QK-only models separately. Aggregators: median,10% trimmed mean,max. Temporal windows:4,16,32. C grid:.01,.1,1,10; class-balanced logistic regression, liblinear, seed1234. Fit every normalization inside five stratified family folds. Select an operating point with strict `R > tauR`, prioritizing mentionFPR<=.20 and maximizing recall. Among admissible variants rank discovery OOF AUROC, then T-versus-M AUROC, then smaller C. If none reaches recall.80, retain the best constrained rule and explicitly record the failed discovery target; do not manufacture an operating point.
- Baselines: last32 native-token text using character2–5gram TF-IDF(max256 features, supporting English and Chinese), log absolute/generated-token positions, a fixed bilingual visual-word indicator, and the first decoder layer's contextual state reduced to16 PCs within each training fold. All use the same C grid and grouped folds. Sink-release is a secondary comparison that cannot replace the primary rule.
- Fit final models on discovery only. Apply the frozen discovery OOF-derived thresholds to confirmation without calibration or retuning. Use OOF R values for discovery state counts, not in-sample fitted scores. Selected OOF metrics are model-selection statistics, not held-out evidence.
- Main G distributions must be characterized before choosing tauG. Preserve both first-query visual-off JS and full evidence-span CE, source-relative diagnostics, and cheap ratios. A common leading digit can make first-query influence weak while later span transport is strong; report this distinction. No main S outcome is examined before R/G definitions and thresholds are frozen.
- Define the causal-confirmation subset by the first12 source/readout-eligible T events per split in frozen manifest/annotation order, before outcomes. Value assays can run after threshold freeze, together with the eligible highR/lowG events; label validation does not retroactively relabel the semantic ground truth.
- Family bootstrap uses4000 resamples, seed1234, keeping every event from each sampled family together. Confirmation model comparison uses paired family resamples. Interpret “clearly outperforms lexical/position baselines” as a positive paired AUROC difference with a95% interval excluding0 against each of those two baselines. Report inconclusive differences honestly; do not change this convention after seeing confirmation.
- Gate2 reports all predicted highR/lowG events and families, held-out persistence, and their T/M/nearby/nonvisual composition; also give T-only and source/readout-eligible counts. A state enriched in false positives is not strong evidence for a retrieval-specific intervention even if its raw count reaches24.
- Gate3 uses strict positive semantic-minus-sham per evaluable event, median effect within each family followed by the median across families, and a family bootstrap95% interval. Missing controls are exclusions with their own denominators. Report gate arithmetic and evidence-coverage limits separately; tiny/nonrepresentative evaluable coverage must not support a broad intervention claim.
- Cheap transport metrics are evaluated against the same frozen causal weakness definition, with discovery-only fitting and held-out correlations/classification. These Value-derived quantities never enter primary R.
- Preserve caps, wrong claims, exclusions, runtime failures and negative evidence. Stop after the Stage8A gate report and one justified next-step recommendation; do not execute the recommendation.
