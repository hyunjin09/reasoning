# Stage10B pre-signal source-diversity clarification

The Strong GO natural-task source rule refers to the two benchmark sources:
MathVision and MathVerse. Apply both ≥8 from each and maximum75% from one to the
same canonical benchmark-source labels. Original source metadata (e.g. GeoQA) and
MathVision subject metadata (e.g. algebra) are different dimensions; preserve them
in the manifest and descriptive tables, without treating them as mutually
exclusive source-type labels in a pooled gate. Visual target types are reported
separately. This clarifies metadata interpretation before any C5 signals are opened;
it does not change the candidate definition, corpus or numerical thresholds.
