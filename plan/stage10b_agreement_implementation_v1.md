# Stage10B raw agreement implementation

Recorded before any per-event passive values are opened. Preserve both independent
semantic passes and their pre-adjudication labels. Main adjudication verifies that
proposed onset-proximity matches refer to the same B fact/source; proximity alone
does not establish identity.

Report trajectory-level C1–C4 agreement on all224 eligible trajectories. Report
prior-availability agreement on semantically matched event pairs, and a separate
union analysis with NOT_NOMINATED for unmatched events so detection disagreements
cannot be hidden by restricting to matched pairs. Report onset agreement within
±8 tokens and source-identity agreement for proposed matched pairs, with n.

For C5, both independent reviewers receive the same sealed semantic anchors/ROIs
and32-row routing measurements, without the computed C5 decision, other reviewer
labels or causal outcomes. Report their raw C5 agreement separately. Raw final
clean-trajectory agreement combines each reviewer's original C1–C4 decisions with
that reviewer's C5 assessment of the corresponding matched/adjudicated event. A
previously un-nominated event does not retroactively become an original semantic
positive. Report disagreement reasons and the final adjudication separately.

Strong-GO agreement checks use matched-event availability raw≥.80/kappa≥.60,
raw final clean-trajectory raw≥.80/kappa≥.60, and matched onset/source agreement
≥.80. Also disclose the stricter event-union availability and original semantic
trajectory agreement as sensitivity/context. Undefined kappa is not a passing
certificate. Agreement is between model-agent review passes, not independent
human raters; no human-annotation reliability claim is warranted.
