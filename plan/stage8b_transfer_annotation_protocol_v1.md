# Stage8B transfer annotation protocol

Frozen before opening any native trace or scientific score. This operationalizes the already frozen random32-item transfer audit; it does not change R, its threshold or the success/failure taxonomy.

Review each source image, question and the complete first1,536 generated reasoning tokens, or all reasoning if shorter. Do not include the final-answer section. Record actual coverage, including zero eligible events. This is an early-prefix alignment audit, not exhaustive whole-trajectory annotation. Input-only demand labels are already sealed in `outputs/stage8b/annotations/input_demands_v1.json` (23 required,8 text-sufficient,1 uncertain).

In chronological order, annotate the first two distinct, source-identifiable T demands, the first mention-only M and the first obvious nonvisual calculation/query, where present. T requires a local visual fact needed at that point and not already supplied by the question or justified earlier reasoning. A repeated visual name/value alone is M; an unsupported interpretation is U. Explicit fresh visual verification can be T only with a specific source and proposition. Preserve missing/ambiguous labels; do not fill quotas by loosening eligibility. Record L+, L- or unresolved local truth against the source, without inferring final correctness or a causal failure state.

For each selected event preserve an exact quote, local readout, its occurrence in the reviewed prefix, source identity and rationale. The primary query predicts the first token of that literal readout. Use Stage8A's validated exact token-boundary alignment; a common numeric prefix must not shift the anchor. Full prefixes through every event must be reviewed. No attention, retrieval score, model hidden state or causal outcome may select labels or boundaries. Final scoring remains separate from review packets.

Seal all32 per-item reviews, source/token provenance, coverage and event membership before opening R. Then evaluate the original frozen transfer requirements: >=70% of clearly visually demanding items have a reasoning retrieval episode; >=70% of annotated T queries have an active prediction within +/-8 tokens; <=20% high-R at the exact M/nonvisual query anchors, with M and nonvisual also reported separately. The first undefined prediction is excluded, not scored negative. A decisive manual audit requires >=24 T and>=24 hard-negative queries across>=16 reviewed items; otherwise it is inconclusive. Report the actual audited-prefix scope and the fraction of all generated reasoning it covers.

Use the actual32 manifest IDs and actual valid labels for all denominators. No detector recalibration, outcome-based audit replacement or after-the-fact threshold changes. An inconclusive or failed gate is preserved as such.
