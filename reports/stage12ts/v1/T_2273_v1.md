### **Computing $ PR $ and $ PS $**

#### **Distance from $ P $ to $ AC $:**

The line $ AC $ has equation $ qx - py = 0 $, where $ q = b $, $ p = a $. The perpendicular distance from point $ P(t, 0) $ to this line is:

$$
PR = \frac{|q \cdot t - p \cdot 0|}{\sqrt{q^2 + p^2}} = \frac{b t}{\sqrt{a^2 + b^2}}
$$

#### **Distance from $ P $ to $ BD $:**

The line $ BD $ has equation $ qx + py - pq = 0 $, or $ bx + ay - ab = 0 $. The perpendicular distance from $ P(t, 0) $ to this line is:

$$
PS = \frac{|b t + a \cdot 0 - ab|}{\sqrt{a^2 + b^2}} = \frac{b(a - t)}{\sqrt{a^2 + b^2}}
$$

### **Summing $ PR + PS $:**

$$
PR + PS = \frac{b t}{\sqrt{a^2 + b^2}} + \frac{b(a - t)}{\sqrt{a^2 + b^2}} = \frac{b t + b(a - t)}{\sqrt{a^2 + b^2}} = \frac{ab}{\sqrt{a^2 + b^2}}
