- **Allowed Move**: Take some or all blocks from the top of a stack, turn them **upside down**, and place them back in the same position within one move.
- **Goal**: Order all blocks **according to size** (i.e., sort them so that the smallest block is at the bottom and the largest at the top).

This operation corresponds to **reversing a prefix** of the current stack — specifically, the top $ k $ elements are reversed and placed back in place.

This is a classic example in sorting by prefix reversals. In such cases, **reversing the entire stack** is sufficient to sort it if the original stack is in reverse order.

Each move can only reverse a **prefix** of the stack (i.e., from the top). However, **reversing the entire stack** is always the most efficient way to sort a reverse-sorted stack.

- If the stack is already sorted, no moves are needed.
- If the stack is in reverse order, reversing the entire stack gives the correct order in **just one move**.
- Any attempt to use fewer than one move would fail because the stack is not already sorted.
